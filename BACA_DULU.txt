PATCH PERBAIKAN COVER BUKU - Ruang Membaca
============================================
Masalah: cover buku di kartu tampil kepotong (judul cover tidak terbaca)
karena wadah gambar lama tingginya tetap (h-52) padahal cover aslinya
portrait 600x900 (rasio 2:3).

Yang diperbaiki:
1. Kartu buku (BookCard) - dipakai di Katalog, Beranda, Koleksi Unggulan
   landing, Favorit, Wishlist, Riwayat, dan buku terkait di halaman
   detail: wadah cover sekarang rasio portrait 2:3 penuh, cover tampil
   UTUH dari atas sampai bawah.
2. Halaman detail buku: cover besar sekarang rasio 2:3 utuh juga.
3. Katalog tampilan LIST: sekarang menampilkan thumbnail cover asli
   (sebelumnya cuma kotak merah berisi teks judul).

Cara pasang:
1. Ekstrak ZIP ini, timpa ke folder project (C:\xampp\htdocs\RuangMembaca).
2. Jalankan: npm run build
3. Refresh browser pakai Ctrl+F5.

Tidak ada perubahan database, tidak perlu migrate/seeder apa pun.
Catatan: kartu buku jadi lebih tinggi dari sebelumnya - itu wajar,
karena cover buku memang portrait. Jumlah kolom grid tidak berubah.
